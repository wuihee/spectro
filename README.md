# spectro

Tools for analyzing IR spectra: peak detection, peak fitting, deconvolution
of overlapping peaks, and classification of samples by type.

```bash
uv sync                  # install
uv run pytest            # tests
uv run jupyter lab       # demo notebooks in notebooks/
```

- [docs/PLAN.md](docs/PLAN.md): plan, decisions and progress
- [docs/study/](docs/study/README.md): study guide, one file per step
- [docs/LITERATURE.md](docs/LITERATURE.md): literature check and references for each step
